# 设备回归清单

> 相机行为**无法用单元测试覆盖**(需要真实硬件),每次动相机层或做大重构后,
> 按这份清单在真机上走一遍。每项都写明了「怎么判断通过」,不要凭感觉打勾。

**前置**:装好最新 APK,先在设置页确认版本号与预期一致。

---

## A. 启动与基础

- [ ] **能启动**:打开不闪退,能看到取景画面
- [ ] **版本号正确**:设置 → 顶部「当前生效」卡片显示预期版本

## B. 取景

- [ ] **竖屏预览正立**:地面在下、物体不倒
- [ ] **横屏预览正立**:手机横过来(左倒、右倒各试一次),画面仍正立
- [ ] **比例正常**:人不被拉长或压扁(对比真实场景)
- [ ] **定时**:点顶栏「定时」,应在 关 → 3s → 10s → 关 之间循环,开启时数字变蓝
- [ ] **九宫格**:设置里开关能控制显隐;三分线应正好在画面的 1/3、2/3,外框贴合预览边缘
- [ ] **预览铺满**:预览画面必须铺满 4:3 框,四周不能有黑边(有黑边说明 `fitPreview` 退回了 contain)
- [ ] **顶栏**:左侧「专业」能开关参数面板;右侧 定时/闪光/水平/设置 都在
- [ ] **历史缩略图**:左下角圆形按钮显示最近一张照片;无历史时是纯白圆;点击进历史页
- [ ] **锁定按钮**:点 ↻ 变 🔒,界面不再跟随旋转;再点解除
- [ ] **翻转**:切前置后画面正常,再切回后置正常

## C. 拍照

- [ ] **竖拍**:复盘页照片正立
- [ ] **横拍(逆时针)**:复盘页照片正立
- [ ] **横拍(顺时针)**:复盘页照片正立
- [ ] **前置拍**:照片正立(⚠️ 此前未验证过,若异常请记录)
- [ ] **存相册**:系统相册里能找到,且方向正确
- [ ] **照片比例**:和取景框看到的构图一致(不出现"取景框里没有、照片里多出来")

## D. 参数

- [ ] **实时参数**:顶栏显示 `ISO xxx · 1/xxxs`,数值随光线变化
- [ ] **手动曝光**:应用 AI 建议的 ISO/快门后,画面亮度**真的变化**
- [ ] **手动对焦**:对近处设 0.5m 清晰,设 ∞ 变糊(反之亦然)
- [ ] **白平衡**:设 3000K 偏冷、设 6500K 偏暖(方向要正确)
- [ ] **一键应用**:复盘页点「应用参数并重拍」→ 回相机,参数确实变了

## E. AI 建议

- [ ] **实时建议**:等 3 秒,卡片刷新出新建议
- [ ] **拍照不被阻塞**:分析进行中按快门,能立刻拍下
- [ ] **错误可见**:断网后卡片显示具体错误(不是永远转圈)
- [ ] **暂停机制**:连续失败 3 次后自动暂停

## F. 历史

- [ ] **记录生成**:拍照后在「拍照历史」看到新记录
- [ ] **回看**:点开记录能看到当时的评分和建议
- [ ] **按天分组**:显示「今天」「昨天」分组
- [ ] **重启保留**:杀掉 App 重开,记录仍在

## G. 生命周期(容易出问题的地方)

- [ ] **进出设置页**:回主界面后取景画面正常(不黑屏)
- [ ] **进出复盘页**:同上
- [ ] **后台再回前台(5 秒)**:画面恢复,无红字
- [ ] **后台再回前台(60 秒)**:同样恢复(相机服务恢复慢,靠重试窗口兜住)
- [ ] **回来等 3 秒**:自动分析能重新刷新建议
- [ ] **反复前后台**:连续切 3 次,每次都正常
- [ ] **连续快速进出**:重复 5 次,不出现「相机被占用」

---

## 出问题时怎么记录

记录三件事:

1. **哪一项**没过
2. **当时怎么操作**的(竖屏/横屏、从哪个页面进出)
3. **实际看到什么**(黑屏 / 歪了 / 报错文案)

如果涉及方向,附上手机是**顺时针还是逆时针**转的。
